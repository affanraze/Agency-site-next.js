# Branvoy

Branvoy is a modern, professional website built for a creative agency and digital services brand. The project showcases a polished online presence with smooth animations, a responsive layout, and an admin-friendly structure for managing core content.

## Overview

This website is designed to present services, projects, team information, pricing, and contact details in a clean and engaging way. It combines a strong visual experience with a practical content management approach, making it suitable for both client-facing presentation and internal updates.

## Highlights

- Modern and responsive design
- Smooth transitions and animated interactions
- Dedicated pages for services, work, about, and contact
- Admin dashboard for managing content
- SEO-friendly structure and scalable Next.js architecture

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Lenis
- Supabase

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open http://localhost:3000 in your browser.

## Project Structure

- app/ — main pages and routes
- components/ — reusable UI components
- lib/ — data and integration helpers
- public/ — static assets and site data

Branvoy is built to be elegant, scalable, and ready for public deployment.
